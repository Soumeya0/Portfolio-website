Algorithm Visualizer

About Algorithm Visualizer

A full-stack visualization tool that shows how sorting and tree algorithms actually work, step by step — built with a Java/Spring Boot API and a vanilla JS frontend. The goal was to turn abstract algorithm behavior into something you can watch unfold frame by frame, rather than just read about.

Why I Start?

Sorting and tree algorithms are usually taught through static diagrams or lines of code, which makes it hard to actually see what's happening at each step. I wanted a tool that plays algorithm execution back like a video — every comparison, swap, and traversal rendered frame by frame — so the logic clicks visually instead of staying abstract.

Problem Statement and Solution

Problem Statement

  • Algorithms are hard to grasp from static text or code alone.
  • Existing visualizers are often single-algorithm or non-interactive.
  • No easy way to replay each comparison/swap step by step.
  • Leaderboards and progress are easy to spoof without real auth.

Solution

  • Return a full step-by-step history for frame-by-frame playback.
  • Support multiple sorts and tree structures in one tool.
  • Animate every comparison, swap, and traversal visually.
  • Secure JWT auth + BCrypt hashing to protect user data.

Highlights

  • Returns a complete step-by-step history of every comparison and swap for Bubble, Merge, and Quick Sort, enabling frame-by-frame animation
  • Built a stateful tree service (BST, AVL, Heap) supporting insert, search, delete, and multiple traversal methods
  • Implemented JWT authentication with BCrypt password hashing, plus server-side validation to prevent leaderboard spoofing
  • Deployed live: Spring Boot API + PostgreSQL on Railway, frontend on Netlify
