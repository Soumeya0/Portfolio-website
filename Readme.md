# ✿ Soumeya Ahmed | Digital Scrapbook Portfolio

Welcome to my digital scrapbook portfolio! Built with a soft, pastel coquette aesthetic, this website blends the nostalgic, tactile feel of journaling and stationery with modern web development. It showcases my journey as a Computer Engineering student at the University of Ottawa.

---

## ✨ Features

- **🎀 Coquette / Digital Scrapbook Design**: Soft pastel pink and cream color palette, rounded "sticker" aesthetics, and elegant serif typography.
- **🖱️ Interactive Custom Cursor**: A soft pink cursor that transforms on hover, making the site feel tactile and alive.
- **📁 Folder & Sticky Note Layouts**: Hero section designed as a folder tab, and the "About Me" section styled like a pinned sticky note.
- **📝 Sticker Embellishments**: Decorative elements (stars, washi tape, emojis) placed like physical stickers throughout the layout.
- **✨ Floating Sparkles**: Subtle, animated sparkle elements that drift across the hero background for a magical, airy feel.
- **📱 Fully Responsive**: Seamlessly adapts to mobile, tablet, and desktop screens.
- **🎯 Smooth Scroll & Reveal Animations**: Sections fade and slide into view as you scroll down the page.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Typography**: 
  - `Playfair Display` (Elegant Serif for headers)
  - `Inter` (Clean Sans-Serif for body text)
- **Icons**: Font Awesome
- **Animations**: CSS Keyframes & Intersection Observer API

---

## 📂 Folder Structure

```text
.
├── index.html          # Main HTML structure
├── style.css           # All styling (pastel aesthetic, layout, animations)
├── script.js           # Custom cursor, scroll animations, navigation
└── README.md           # Project documentation
```

---

## 🚀 How to Run Locally

1. **Download the files**: Download `index.html`, `style.css`, and `script.js` into a single folder.
2. **Open the project**: Double-click the `index.html` file to open it in your preferred web browser.
3. **Explore**: Hover over elements to see the custom cursor change, and scroll down to watch the cards reveal themselves.
