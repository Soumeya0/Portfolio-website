About Memora

A native iOS memory-journaling app with a scrapbook-inspired design, built to feel personal rather than generic. Memora focuses on making it effortless and delightful to capture and revisit small moments.

Why I Start?

Most journaling apps feel like generic productivity tools, not something you'd actually want to open and revisit. I wanted to build something that felt like a physical scrapbook — warm, personal, and quick to use — so capturing a small moment never feels like a chore.

Problem Statement and Solution

Problem Statement

  • Journaling apps often feel generic and impersonal.
  • Capturing a moment can feel like a chore, not a joy.
  • Data needs to work offline and stay reliably synced.
  • Sign-in and onboarding are often clunky first impressions.

Solution

  • Designed a warm, scrapbook-inspired visual identity.
  • Kept capture flows fast and delightful with custom animations.
  • Built local-first persistence with SwiftData, syncing to Firestore.
  • Added reactive Firebase Auth that routes users automatically.

Highlights

  • Architected local-first persistence with SwiftData, using typed on-device models that stay in sync with the UI automatically
  • Integrated Firebase Authentication with a reactive listener that routes users based on sign-in state
  • Built a reusable SwiftUI animation library (spring transitions, staggered entrances) and a themeable design system
  • Currently extending to Firestore for cloud sync with per-user data ownership
