Memora

A native iOS memory-journaling app with a scrapbook-inspired design, built to feel personal rather than generic. Memora focuses on making it effortless and delightful to capture and revisit small moments.

✦ Highlights

  • Architected local-first persistence with SwiftData, using typed on-device models that stay in sync with the UI automatically
  • Integrated Firebase Authentication with a reactive listener that routes users based on sign-in state
  • Built a reusable SwiftUI animation library (spring transitions, staggered entrances) and a themeable design system
  • Currently extending to Firestore for cloud sync with per-user data ownership
