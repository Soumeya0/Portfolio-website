Application Tracker

A self-hosted job application tracker built with Flask and SQLite. It logs every application, flags what needs attention with automatic urgency highlighting, emails a daily digest before deadlines and follow-ups slip, and rolls everything into a stats dashboard so job hunting stops feeling like a spreadsheet no one opens.

The problem

Tracking job applications in a spreadsheet meant deadlines and follow-ups quietly slipped through the cracks, and there was no easy way to see how the search was actually going. I wanted a small, self-hosted tool that surfaced what needed attention on its own — urgent rows flagged automatically, a daily email digest, and real stats on response rate — so the tracker did the remembering instead of me.

What I built

  • Sortable, filterable application table with automatic urgency highlighting for deadlines and follow-ups due soon or overdue
  • Built a daily email-digest system (smtplib + Gmail SMTP) driven by a standalone scheduler for always-on reminders
  • Stats engine that computes total applications, status breakdown, response rate, and average time to first response
