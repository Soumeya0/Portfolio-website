                    <div>
                        <span class="project-tag">Java / Spring</span>
                        <h2>Algorithm Visualizer</h2>
                    </div>
                </div>

                <p class="project-detail-desc">
                    A full-stack visualization tool that shows how sorting and tree algorithms actually
                    work, step by step — built with a Java/Spring Boot API and a vanilla JS frontend.
                    The goal was to turn abstract algorithm behavior into something you can watch unfold
                    frame by frame, rather than just read about.
                </p>

                <div>
                    <h4>✦ Highlights</h4>
                    <ul class="project-detail-bullets">
                        <li>Returns a complete step-by-step history of every comparison and swap for Bubble, Merge, and Quick Sort, enabling frame-by-frame animation</li>
                        <li>Built a stateful tree service (BST, AVL, Heap) supporting insert, search, delete, and multiple traversal methods</li>
                        <li>Implemented JWT authentication with BCrypt password hashing, plus server-side validation to prevent leaderboard spoofing</li>
                        <li>Deployed live: Spring Boot API + PostgreSQL on Railway, frontend on Netlify</li>
                    </ul>
                </div>
